# Security Policy

ProofGarden handles potentially sensitive uploads and investigation notes. Please treat security and privacy reports carefully.

## Supported Versions

The initial MVP is version `0.1.x`.

## Reporting a Vulnerability

Please do not open public issues for vulnerabilities that expose uploads, local paths, personal data, or report contents. Contact maintainers privately through the project security channel once configured.

Include:

- A short description of the issue
- Reproduction steps
- Impact
- Affected version or commit
- Suggested mitigation if known

## Security Principles

- Uploads are local by default.
- Reports should not publish private data without review.
- Analysis modules should avoid sending evidence to third-party services unless explicitly enabled.
- Future integrations must document privacy behavior before release.
