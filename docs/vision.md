# Vision

ProofGarden exists to make verification work calmer, more transparent, and easier to review.

The project is built around a simple idea: evidence should grow in context. A screenshot, message, file, or public claim is rarely enough by itself. Investigators need source links, notes, metadata, timelines, uncertainty, and a report that explains how a conclusion was reached.

## Product Principles

- Evidence first, conclusions second.
- Transparent scoring over black-box labels.
- Human judgment remains central.
- Privacy should be the default.
- Community modules should be testable and documented.

## Non-Goals

- ProofGarden is not a universal truth machine.
- ProofGarden is not a tool for identifying private individuals.
- ProofGarden is not a replacement for forensic specialists.
- ProofGarden should not encourage harassment or public shaming.
