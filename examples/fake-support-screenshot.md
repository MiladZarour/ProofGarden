# Fake Support Screenshot

This is a fake example for testing ProofGarden.

## Scenario

A screenshot appears to show a support agent from "AcmeCloud Helpdesk" asking a user to share a one-time login code.

## Visible Text

Agent: Hello Riley, your account is blocked. Send us the one-time code to restore access immediately.  
User: I thought support never asks for codes.  
Agent: This is the final warning before permanent suspension.

## Notes

- The request for a one-time code is a strong account takeover signal.
- The pressure language should be documented as a text clue.
- The screenshot alone does not prove who sent the message.
